# Agent Routing Rules

- If the task is about agency/client WordPress work (Flatsome child themes, UX Builder pages, business-data code in functions.php, or packaging/handover): Route to `wp-agency-router`.
- If the task is about other WordPress work (blocks, block themes, REST, WP-CLI, performance): Route to the official upstream `wordpress-router` (if available).
- Do not use this pack's skills for generic WordPress core development unless specifically related to Flatsome, functions.php business logic, or handovers.

---
Nếu tác vụ liên quan đến theme Flatsome, chức năng functions.php hoặc bàn giao dự án: Chuyển hướng cho `wp-agency-router`. Với các việc khác: nhường quyền cho upstream `wordpress-router`.
